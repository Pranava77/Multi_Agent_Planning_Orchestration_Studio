Side-by-side head-to-head comparison of Plan-and-Solve vs ReAct vs Multi-Agent Dynamic Replanning.

Plan-and-Solve (P&S) Static

Upfront static decomposition. Breaks the goal into a linear sequence and executes blindly without verifying intermediate observations.

[1] Step 1: SQL Query executed.
[2] Step 2: Knowledge search done.
[3] Step 3: Math aggregation run.
[4] Step 4: Discrepancy detected!
[5] Step 5: FAILED — blindly synthesized unverified data.
68.4% success 0% recovery
Single Agent ReAct Trial & Error

Iterative Think → Act → Observe loop with a single generalist agent. Suffers from cognitive overload across multiple domains.

[1] Thought: Let me check SQL.
[2] Action: SQL query.
[3] Thought: Let me do math in text.
[4] Obs: Calculation error!
[5] Thought: Let me retry query.
[6] Action: Repeated SQL query.
[7–11] Context polluted. Slow convergence.
78.2% success 10.8 avg steps
Multi-Agent + Replanning Collaborative DAG

Supervisor DAG decomposition + Role Specialists (SQL, Quant, Reviewer). Dynamically adjusts remaining subtasks if anomalies arise.

[1] SQL Specialist executes schema query.
[2] Quant Analyst computes EBITDA accurately.
[3] Critical Reviewer detects $61.8M gap.
[4] REPLAN TRIGGERED: Injected deep-dive.
[5] Reconciled ledger line-by-line.
[6] Supervisor delivers verified audit synthesis.
